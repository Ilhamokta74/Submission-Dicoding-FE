Jurnal singkat perjalanan saya belajar membuat website dari nol.

Dari Penasaran Jadi Kebiasaan

Awal Mula

Saya mulai belajar web development karena mendapatkan kesempatan mengikuti MSIB Batch 2, saya ingin tahu bagaimana sebuah halaman bisa tampil di layar hanya dari beberapa baris teks. Ternyata semuanya dimulai dari HTML: kerangka yang memberi arti pada setiap bagian halaman.

Submission ini adalah halaman pertama yang saya susun sendiri, lengkap dengan struktur semantik dan tata letak berbasis flexbox.

Yang Dipelajari

Beberapa hal penting yang saya dapat selama mengerjakan halaman ini:

  • Elemen semantik seperti header, nav, main, article, aside, dan footer membuat struktur halaman lebih mudah dipahami.
  • Flexbox memudahkan penataan kolom tanpa perlu float.
  • Menggunakan relative path agar gambar dan stylesheet tetap terbaca di komputer lain.

Target Berikutnya

Setelah memahami dasar HTML dan CSS, saya ingin lanjut mempelajari JavaScript agar halaman bisa bereaksi terhadap aksi pengunjung.
